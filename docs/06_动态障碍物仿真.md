# 06 动态障碍物仿真

> **适用环境：** Ubuntu 20.04 + ROS Noetic + Gazebo 11 Classic + PX4 v1.13
> **目标：** 使用 `dynamic_obstacles` 功能包在仿真中加载高逼真、高度可控的动态障碍物（无人机 + 海鸥），用于动态避障测试。

---

## 1. 功能概述

`dynamic_obstacles` 是为 PX4 + Gazebo Classic + ROS1 开发的动态障碍物仿真管理包，主要特性：

1. **导入 3D Warehouse 真实海鸥模型（ARGO）**
   - 通过 `model.sdf` + `model.config` 直接加载 `.dae` 网格与 JPEG 贴图，无需转 SDF。
   - 已处理 SketchUp 英寸 → 米缩放（`0.0254` 比例），尺寸真实。
2. **RViz 交互式「指哪飞哪」**
   - 默认 `interactive` 模式，障碍物启动时静态加载在天空。
   - RViz 中点击「2D Nav Goal」可让最近障碍物飞向指定点。
   - 支持向话题 `/select_obstacle` 发送名字锁定特定障碍物。
3. **高速可控**：障碍物飞行速度默认 6.0 m/s（可调），满足高速避障测试。

## 2. 目录结构

```
dynamic_obstacles/
├── CMakeLists.txt
├── package.xml
├── README.md
├── run_simulation.sh            # 一键启动脚本
├── launch/
│   └── start_simulation.launch  # 核心 launch（支持 num_drones/num_birds/control_mode/target_speed）
├── models/
│   ├── iris_obstacle/           # 亮红色轻量 iris 障碍物
│   └── ARGO/                    # 真实海鸥模型（model.dae + 贴图）
└── scripts/
    └── obstacle_controller.py   # 50Hz 轨迹解析 / 调头 / 瞬时速度计算
```

## 3. 部署步骤

```bash
# 1. 将整个功能包复制到工作空间（本包已放在 dynamic_obstacles/）
cp -r dynamic_obstacles ~/catkin_ws/src/

# 2. 编译
cd ~/catkin_ws
catkin_make
source devel/setup.bash
```

## 4. 运行

默认交互模式，6 架无人机 + 6 只海鸥，速度 6.0 m/s：

```bash
~/catkin_ws/src/dynamic_obstacles/run_simulation.sh
```

拉满规模（10 + 10，速度 8.0）：

```bash
~/catkin_ws/src/dynamic_obstacles/run_simulation.sh num_drones:=10 num_birds:=10 target_speed:=8.0
```

## 5. 交互控制（RViz）

Gazebo 与 RViz 打开后：

1. RViz 界面中看到静态分布天空的障碍物。
2. 点击 RViz 工具栏 **「2D Nav Goal」**。
3. 在地图上任意位置点击一下 —— 距离点击位置最近的障碍物会平滑调头、以设定速度飞向目标点。
4. 再次点击可控制另一个最近的障碍物。
5. **手动锁定（可选）**：新开终端发布名字到选择话题：

```bash
rostopic pub -1 /select_obstacle std_msgs/String "data: 'obs_drone_3'"
```

之后点击「2D Nav Goal」时，只有 `obs_drone_3` 会飞过去。

6. **恢复自由轨迹模式**：绕圈/飞八字：

```bash
~/catkin_ws/src/dynamic_obstacles/run_simulation.sh control_mode:=trajectory
```

## 6. 参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `num_drones` | 6 | 无人机障碍物数量 |
| `num_birds` | 6 | 海鸥障碍物数量 |
| `control_mode` | `interactive` | `interactive`（交互）/ `trajectory`（轨迹） |
| `target_speed` | 6.0 | 飞行速度（m/s） |

---

## 7. 常见问题

**问题：障碍物不动**
- 确认 `control_mode` 参数正确；`interactive` 模式需在 RViz 中点击「2D Nav Goal」触发。

**问题：海鸥模型不显示**
- 确认 `models/ARGO/` 完整（含 `model.dae` 与 `model/` 贴图文件夹）。
