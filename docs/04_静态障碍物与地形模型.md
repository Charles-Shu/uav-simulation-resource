# 04 静态障碍物与地形模型

> **适用环境：** Ubuntu 20.04 + Gazebo 11 Classic + PX4 v1.13
> **目标：** 说明沙地、水体、高压线塔等自定义静态障碍物/地形模型的用途与使用方法。

---

## 1. 概述

这些模型用于在 Gazebo 场景中布置**静态障碍物与地形**，供无人机避障、目标识别、地形感知等测试使用。启动仿真后可直接拖入场景，也可写进 `.world` 文件随场景加载。

模型统一存放在本包的 `models/terrain_obstacles/` 下，使用前整体复制到：

```
~/PX4-Autopilot/Tools/sitl_gazebo/models/
```

## 2. 模型目录结构

每个模型是一个独立文件夹，标准结构如下：

```
模型名/
├── model.config      # 模型描述文件（名称、作者、版本）
├── model.sdf         # SDF 定义（几何、碰撞、材质、位姿）
├── meshes/           # 网格文件（.dae / .stl）
└── materials/        # 材质/贴图
```

## 4. 使用方法

### 方法一：拖入 Gazebo（临时布置）

1. 启动仿真后，Gazebo 左侧 `Insert` 面板中会列出模型库。
2. 搜索模型名（如 `sandland4`），点击后在地面放置。

### 方法二：写入 .world 文件（随场景加载）

在 `.world` 文件中添加 `<include>` 引用：

```xml
<include>
  <uri>model://electric_tower</uri>
  <pose>10 10 0 0 0 0</pose>
</include>
```

### 方法三：放入其他模型库

若模型在 `Insert` 面板中不显示，把模型文件夹复制到模型搜索路径即可：

```bash
cp -r models/terrain_obstacles/* ~/PX4-Autopilot/Tools/sitl_gazebo/models/
```

## 5. 常见问题

**问题：拖入模型后看不到或不显示**
- 确认模型已放入 `~/PX4-Autopilot/Tools/sitl_gazebo/models/`；
- 确认 `model.config` 中的模型名与文件夹名一致；
- 重启 Gazebo 刷新模型库。

**问题：模型没有碰撞体**
- 部分早期地形模型只用于视觉，未配置 `<collision>`，无人机可能穿过。如需碰撞，在 `model.sdf` 中补充 collision 几何。
