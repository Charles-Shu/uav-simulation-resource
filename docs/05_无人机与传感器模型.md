# 05 无人机与传感器模型

> **适用环境：** Ubuntu 20.04 + Gazebo 11 Classic + PX4 v1.13
> **目标：** 说明自建的无人机机型与传感器模型，指导如何选择与切换机型。

---

## 1. 概述

默认仿真使用 PX4 自带的 `iris` 四旋翼。为满足不同任务（搭载激光雷达、深度相机、仿实机参数等），后续自建/改造了一批机型与传感器模型。本包已将它们整理到：

- `models/uav/`：无人机整机模型
- `models/sensors/`：传感器模型（被无人机 sdf 引用）

使用前整体复制到 `~/PX4-Autopilot/Tools/sitl_gazebo/models/`。

## 4. 重点机型：matrice_100_D435i_real

该机型是**仿照实机设置参数**、并搭载 Mid-360 与 D435i 传感器的无人机，用于尽可能贴近实机的仿真。

关键点：

- 它搭载的传感器**不是**基础版 `Mid360` / `D435i`，而是修改质量后的 **`Mid360_real`** / **`D435i_real`**。
- 因此该机型依赖四个传感器模型文件夹：`Mid360`、`Mid360_real`、`D435i`、`D435i_real`（`_real` 变体基于基础版改造而来，故四个都需保留）。本包 `models/sensors/` 已全部包含。

**使用前请确认这四个文件夹都已复制到 `~/PX4-Autopilot/Tools/sitl_gazebo/models/`**，否则模型会因找不到传感器引用而加载失败。

## 5. 机型依赖关系

自定义无人机 sdf 会引用传感器模型，例如：

```
matrice_100_D435i_real.sdf  →  引用 Mid360_real.sdf / D435i_real.sdf
iris_mid360_D435i_final.sdf →  引用 Mid360.sdf / D435i.sdf
```

因此**传感器模型与无人机模型必须一起部署**，缺一不可。

## 6. 如何切换机型

修改 `~/PX4-Autopilot/launch/mavros_posix_sitl.launch` 中的机型参数：

```xml
<arg name="model" default="matrice_100_D435i_real"/>
<arg name="sdf" default="$(find mavlink_sitl_gazebo)/models/$(arg model)/$(arg model).sdf"/>
```

或启动时用命令行覆盖：

```bash
roslaunch px4 mavros_posix_sitl.launch model:=matrice_100_D435i_real
```

## 7. PX4 自带机型说明

以下机型为 PX4 v1.13 **自带**，克隆 PX4 后即可直接使用，无需从本包额外拷贝：

- `iris`（默认）
- `iris_depth_camera`
- `iris_downward_camera`
- `iris_downward_depth_camera`
- `iris_obs_avoid`、`iris_vision` 等

## 8. 常见问题

**问题：启动时报 `Model [Mid360_real] not found`**
- 说明传感器模型未部署。确认 `Mid360_real` 等四个传感器文件夹已复制到模型库。

**问题：点云/图像话题为空**
- 确认已激活传感器驱动工作空间（见 [02_传感器搭载_mid360_D435i.md](02_传感器搭载_mid360_D435i.md)），并检查 `Mid360.sdf` 里的 csv 路径是否指向本机正确路径。
