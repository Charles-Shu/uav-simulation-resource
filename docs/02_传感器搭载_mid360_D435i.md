# 02 给无人机搭载 Mid-360 与 D435i

> **适用环境：** Ubuntu 20.04 + ROS Noetic + PX4 v1.13.0 + Gazebo 11 Classic
> **目标：** 让 Livox Mid-360 激光雷达与 Intel RealSense D435i 深度相机在仿真中正常发布点云/图像话题。

---

## 前置说明

1. **统一工作空间**：`livox_ros_driver2` 与 `livox_laser_simulation`（即 `Mid360_imu_sim`）放在同一个 ROS 工作空间 `~/catkin_ws` 下。
2. **全局激活**：将 `~/catkin_ws/devel/setup.bash` 写入 `~/.bashrc`，避免每次手动 `source`。

---

## 步骤一：安装 Livox-SDK2

```bash
git clone https://github.com/Livox-SDK/Livox-SDK2.git
cd ./Livox-SDK2/
mkdir build && cd build
cmake .. && make -j
sudo make install
```

---

## 步骤二：编译 livox_ros_driver2

Mid-360 必须用 `livox_ros_driver2` 驱动（`livox_ros_driver` 不兼容）。

```bash
mkdir -p ~/catkin_ws/src
cd ~/catkin_ws/src
git clone https://github.com/Livox-SDK/livox_ros_driver2.git
cd livox_ros_driver2
./build.sh ROS1
source ~/catkin_ws/devel/setup.bash
# 验证（无报错即基本正常）
roslaunch livox_ros_driver2 [launch file]
```

---

## 步骤三：安装 livox_laser_simulation（Gazebo 仿真插件）

该仓库有三个分支，拉取不同分支，Mid-360 发布的点云消息类型不同：

| 分支 | 消息类型 |
|------|----------|
| main | `sensor_msgs/PointCloud` |
| PointCloud2_1 | `sensor_msgs/PointCloud2` |
| Custom | `livox_ros_driver2/CustomMsg` |

**推荐拉取 `Custom` 分支**：无需消息转换，可直接喂给 Fast-LIO 等算法。

```bash
cd ~/catkin_ws/src
git clone -b Custom https://github.com/qiurongcan/Mid360_imu_sim.git
cd ~/catkin_ws
catkin_make
source devel/setup.bash
# 验证
roslaunch livox_laser_simulation livox_simulation.launch
# 或使用带 IMU 的版本
roslaunch livox_laser_simulation mid360_IMU_platform.launch
```

> **注意 1**：本包只保留了 Mid-360 的扫描文件，如需其他雷达型号请参考原仓库 `https://github.com/Livox-SDK/livox_laser_simulation.git`。
> **注意 2**：使用 IMU 版本时雷达输出两个话题，标准版只有一个：
> - `/scan`（`livox_ros_driver2/CustomMsg`）
> - `/lidar/imu`

### 确认文件路径正确

1. 将完整的 Mid360 雷达模型文件夹放入 PX4 仿真模型总目录：

```bash
ls -la ~/PX4-Autopilot/Tools/sitl_gazebo/models/Mid360/
```

2. 确认雷达扫描模式文件 `mid360.csv` 存在：

```bash
ls -la ~/catkin_ws/src/Mid360_imu_sim/scan_mode/
```

正常目录结构：

```
Mid360/
├── livox_mid40/          # 雷达网格模型子文件夹
├── livox_avia.sdf
├── livox_mid70.sdf
├── Mid360.sdf            # 雷达核心配置文件
└── model.config
scan_mode/
└── mid360.csv            # Mid360 专属扫描轨迹文件
```

> 说明：`Mid360/` 模型目录内可能同时存在多个 `.sdf` 文件（`Mid360.sdf`、`Mid360_real.sdf`、`Mid3601.sdf`、`Mid360_cpu.sdf`、`Mid360_gpu.sdf` 等）。**正式使用时用 `Mid360.sdf`**（普通机型）或 **`Mid360_real.sdf`**（仿实机参数机型，如 `matrice_100_D435i_real`），其余为调试/备份文件，可忽略。

---

## 步骤四：安装 D435i 所需驱动和插件

### 4.1 安装 realsense 仿真驱动

```bash
cd ~/catkin_ws/src
git clone https://gitee.com/nie_xun/realsense_ros_gazebo.git
cd ~/catkin_ws
catkin_make
source devel/setup.bash
# 验证
roslaunch realsense_ros_gazebo simulation_D435i_sdf.launch
# 或
roslaunch realsense_ros_gazebo simulation.launch
```

### 4.2 拷贝仿真插件

```bash
cd ~/catkin_ws
cp devel/lib/librealsense_gazebo_plugin.so ~/PX4-Autopilot/build/px4_sitl_default/build_gazebo/
```

> 本资源包已附带了编译好的插件：`sensor_plugins/compiled/librealsense_gazebo_plugin.so`，可直接拷贝使用，无需重复编译。

---

## 步骤五：Mid360 文件必要配置

修改 `Mid360/Mid360.sdf` 中读取 csv 的路径（约第 71 行），**必须改成你自己电脑的实际路径**：

```xml
<downsample>1</downsample>
<csv_file_name>/home/sf/PX4-Autopilot/Tools/sitl_gazebo/models/Mid360/livox_mid40/scan_mode/mid360.csv</csv_file_name>
<ros_topic>/scan</ros_topic>
```

---

## 步骤六：复制最终模型到 PX4 模型库

```bash
cd ~/catkin_ws/src/realsense_ros_gazebo/sdf
cp -r D435i ~/PX4-Autopilot/Tools/sitl_gazebo/models/
cp -r iris_mid360_D435i ~/PX4-Autopilot/Tools/sitl_gazebo/models/
```

- `iris_mid360_D435i` 是已搭载好 Mid-360 和 D435i 的 iris 无人机（含 sdf 与 config）。
- `D435i` 也必须复制进模型库，因为 `iris_mid360_D435i.sdf` 会引用它。

> 本资源包已把无人机、传感器模型整理在 `models/uav/` 与 `models/sensors/` 下，可直接整体拷贝到 `~/PX4-Autopilot/Tools/sitl_gazebo/models/`。模型清单见 [05_无人机与传感器模型.md](05_无人机与传感器模型.md)。

---

## 步骤七：验证

1. 修改 `~/PX4-Autopilot/launch/mavros_posix_sitl.launch`，把无人机型号改成新搭载的机型。
2. **务必先激活 `livox_laser_simulation` 所在工作空间**，否则没有雷达点云话题。

```bash
# terminal 1：弹出搭载 Mid-360 和 D435i 的无人机
roslaunch px4 mavros_posix_sitl.launch

# terminal 2：查看话题
rostopic list
```

**补充**：若配合 Fast-LIO2 等算法，在 `mid360.yml` 中使用：

```yaml
lidar_topic: /scan
imu_topic: /mavros/imu/data
```
