# 01 仿真环境搭建（Ubuntu 20.04 + ROS Noetic + Gazebo 11 + PX4 v1.13）

> **适用环境：** Ubuntu 20.04（x86_64）
> **目标：** 完成 ROS1、PX4、MAVROS、QGroundControl 的安装与联调，使其可以启动 PX4 + Gazebo 仿真并控制无人机。

---

## 1. 安装 ROS Noetic

### 1.1 配置软件源

```bash
# 1. 配置 sources.list
sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list'

# 2. 添加密钥
sudo apt install curl
curl -s https://raw.githubusercontent.com/ros/rosdistro/master/ros.asc | sudo apt-key add -
```

### 1.2 安装 ROS

```bash
# 1. 更新软件包索引
sudo apt update

# 2. 安装完整版 ROS（推荐，含 rqt/rviz/Gazebo 等）
sudo apt install ros-noetic-desktop-full
```

> 版本说明：`desktop-full`（推荐，含仿真器）＞ `desktop`（含 rqt/rviz）＞ `base`（仅核心库）＞ `core`（仅通信库）。本项目使用 **full** 版。

### 1.3 初始化 rosdep

```bash
sudo apt install python3-rosdep python3-rosinstall python3-rosinstall-generator python3-wstool build-essential
sudo rosdep init
rosdep update
```

### 1.4 环境配置

```bash
# 将 ROS 环境变量写入 bashrc，每次打开终端自动加载
echo "source /opt/ros/noetic/setup.bash" >> ~/.bashrc
source ~/.bashrc
```

### 1.5 安装常用工具

```bash
sudo apt install ros-noetic-rqt ros-noetic-rqt-common-plugins ros-noetic-tf2-tools ros-noetic-tf
sudo apt install python3-catkin-tools python3-osrf-pycommon
```

### 1.6 创建 ROS 工作空间

```bash
mkdir -p ~/catkin_ws/src
cd ~/catkin_ws/
catkin_make
echo "source ~/catkin_ws/devel/setup.bash" >> ~/.bashrc
source ~/.bashrc

# 验证：应输出 /home/<用户名>/catkin_ws/src:/opt/ros/noetic/share
echo $ROS_PACKAGE_PATH
```

目录结构：

```
catkin_ws/
├── build/       # 编译目录
├── devel/       # 开发目录
└── src/         # 源码目录
    └── CMakeLists.txt
```

## 2. 安装 PX4 v1.13

### 2.1 克隆源码

```bash
git clone -b v1.13.0 https://github.com/PX4/PX4-Autopilot.git --recursive
```

进入 `PX4-Autopilot` 目录，确保子模块完整：

```bash
cd PX4-Autopilot/
git submodule update --init --recursive
```

### 2.2 修改 requirements.txt（重要，否则安装脚本报错）

进入 `PX4-Autopilot/Tools/setup`，打开 `requirements.txt`，将第 11 行的 matplotlib 版本改为：

```
matplotlib==3.0.*
```

若不修改，运行 `ubuntu.sh` 时会因 matplotlib 版本依赖报错。

### 2.3 运行工具链安装脚本

```bash
cd ~/PX4-Autopilot
bash ./Tools/setup/ubuntu.sh
```

### 2.4 编译 PX4

重启系统后：

```bash
cd ~/PX4-Autopilot/
make px4_sitl_default
```

编译完成后，可在 SITL 控制台输入 `commander takeoff` 控制起飞、`commander land` 控制降落。

### 2.5 配置 Gazebo 环境变量

推荐使用本项目提供的**一键环境脚本**（见 [scripts/setup_all_env.sh](../scripts/setup_all_env.sh)），复制到 `~/` 后，每次启动仿真前执行：

```bash
source ~/setup_all_env.sh
```

该脚本会自动加载 ROS、catkin 工作空间、PX4 Gazebo 环境，并设置 `ROS_PACKAGE_PATH`、修复 Intel 核显 Gazebo 黑屏问题（`SVGA_VGPU10=0`、`INTEL_DEBUG=noccs`）。

> 若不想用脚本，也可手动在 `~/.bashrc` 末尾添加：

```bash
# ====================== PX4 1.13 仿真环境配置 ======================
PX4_DIR=~/PX4-Autopilot
PX4_BUILD_DIR=$PX4_DIR/build/px4_sitl_default

source $PX4_DIR/Tools/setup_gazebo.bash $PX4_DIR $PX4_BUILD_DIR

export ROS_PACKAGE_PATH=$ROS_PACKAGE_PATH:$PX4_DIR
export ROS_PACKAGE_PATH=$ROS_PACKAGE_PATH:$PX4_DIR/Tools/sitl_gazebo
# ==================================================================
```

## 3. 安装 MAVROS

```bash
sudo apt-get install ros-noetic-mavros ros-noetic-mavros-extras
# 安装 GeographicLib 数据集
sudo /opt/ros/noetic/lib/mavros/install_geographiclib_datasets.sh
```

---

## 4. 安装地面站 QGroundControl

```bash
# 下载依赖
sudo apt install gstreamer1.0-plugins-bad gstreamer1.0-libav gstreamer1.0-gl -y
sudo apt install libfuse2 -y
sudo apt install libxcb-xinerama0 libxkbcommon-x11-0 libxcb-cursor-dev -y
```

前往官方 GitHub 下载 **V4.4.4 及以前版本**的 AppImage，然后：

```bash
cd ~/Downloads
sudo chmod +x QGroundControl.AppImage
```

可根据需要创建桌面快捷方式。

---

## 5. 常见报错及解决办法

**问题：执行 `roslaunch` 提示找不到文件**

> 原因：PX4 的 Gazebo 环境变量未加载。

每次打开新终端执行一次：

```bash
cd ~/PX4-Autopilot
source Tools/setup_gazebo.bash $(pwd) $(pwd)/build/px4_sitl_default
export ROS_PACKAGE_PATH=$ROS_PACKAGE_PATH:$(pwd)
export ROS_PACKAGE_PATH=$ROS_PACKAGE_PATH:$(pwd)/Tools/sitl_gazebo
```

或直接 `source ~/setup_all_env.sh`。

## 6. 验证

完成上述步骤后，执行：

```bash
source ~/setup_all_env.sh
roslaunch px4 mavros_posix_sitl.launch
```

应弹出 Gazebo 窗口并加载默认 `empty.world`，出现 iris 无人机。新开终端 `rostopic list` 可看到 `/mavros/*` 等话题。
