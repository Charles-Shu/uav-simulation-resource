# 03 世界场景（World）的使用与切换

> **适用环境：** Ubuntu 20.04 + ROS Noetic + PX4 v1.13 + Gazebo 11 Classic
> **目标：** 理解 `.world` 文件的原理，掌握自定义场景的存放、加载与快速切换。

---

## 1. 核心原理

Gazebo 的世界场景由 `.world` 文件定义。启动脚本 `launch` 文件中控制世界文件的参数是这一行：

```xml
<arg name="world" default="$(find mavlink_sitl_gazebo)/worlds/empty.world"/>
```

- `$(find mavlink_sitl_gazebo)`：自动查找 `mavlink_sitl_gazebo` 功能包的路径。
- `/worlds/empty.world`：该功能包下的世界文件路径。

只要改这一个参数，就能更换整个仿真场景。

---

## 2. 推荐的文件存放结构

**强烈建议**不要把自定义世界文件直接放进 PX4 目录，否则 PX4 更新时会丢失。正确做法是：在 `catkin_ws` 中创建一个**专门存放自定义世界和模型的功能包**，与 PX4 完全隔离。本项目即采用此方案（功能包 `my_gazebo_worlds`，已打包在 [../worlds/](../worlds/) 中）。

```bash
cd ~/catkin_ws/src
catkin_create_pkg my_gazebo_worlds std_msgs rospy roscpp
mkdir -p ~/catkin_ws/src/my_gazebo_worlds/worlds
mkdir -p ~/catkin_ws/src/my_gazebo_worlds/models

# 编译
cd ~/catkin_ws
catkin_make
source devel/setup.bash
```

把 `.world` 文件放入：

```
~/catkin_ws/src/my_gazebo_worlds/worlds/my_world.world
```

---

## 3. 修改 launch 文件

只需修改一行，其余保持不变：

```xml
<!-- 原来的空地图 -->
<!-- <arg name="world" default="$(find mavlink_sitl_gazebo)/worlds/empty.world"/> -->

<!-- 替换为你的自定义世界 -->
<arg name="world" default="$(find my_gazebo_worlds)/worlds/my_world.world"/>
```

若同时要换无人机型号，可参考以下片段：

```xml
<arg name="est" default="ekf2"/>
<arg name="vehicle" default="iris"/>
<arg name="model" default="iris_mid360_D435i"/>   <!-- 自定义机型 -->

<arg name="world" default="$(find my_gazebo_worlds)/worlds/my_world.world"/>
<arg name="sdf" default="$(find mavlink_sitl_gazebo)/models/$(arg model)/$(arg model).sdf"/>
```

---

## 4. 在 Gazebo 中手动保存场景

若是在 Gazebo 界面里手动搭建的场景，可直接保存为 `.world`：

1. Gazebo 界面左上角 `File → Save World As`。
2. 保存路径选 `~/catkin_ws/src/my_gazebo_worlds/worlds/`。
3. 输入文件名（如 `my_world.world`），点击保存。

---

## 5. 快速切换多个世界（无需改 launch）

启动时用命令行参数 `world:=` 覆盖默认值：

```bash
# 空地图
roslaunch px4 mavros_posix_sitl.launch world:=$(rospack find mavlink_sitl_gazebo)/worlds/empty.world

# 自定义世界
roslaunch px4 mavros_posix_sitl.launch world:=$(rospack find my_gazebo_worlds)/worlds/my_world.world

# PX4 自带室内世界
roslaunch px4 mavros_posix_sitl.launch world:=$(rospack find mavlink_sitl_gazebo)/worlds/indoor1.world
```

## 7. 常见问题及解决方案

### 问题 1：Gazebo 找不到世界文件
> 报错：`Could not find file [xxx.world]`

- 确认文件路径正确；
- 确认已执行 `catkin_make` 和 `source devel/setup.bash`；
- 可用绝对路径测试：`<arg name="world" default="/home/sf/catkin_ws/src/my_gazebo_worlds/worlds/my_world.world"/>`。

### 问题 2：世界文件中的模型无法加载
> 报错：`Model [xxx] not found`

将世界文件引用的所有自定义模型复制到：

```
~/catkin_ws/src/my_gazebo_worlds/models/
```

或将模型路径加入环境变量：

```bash
echo "export GAZEBO_MODEL_PATH=$GAZEBO_MODEL_PATH:/home/sf/catkin_ws/src/my_gazebo_worlds/models" >> ~/.bashrc
source ~/.bashrc
```

### 问题 3：启动后无人机位置不对

修改 launch 文件中的初始位置参数：

```xml
<arg name="x" default="0"/>
<arg name="y" default="0"/>
<arg name="z" default="1"/>  <!-- 抬高初始高度，避免卡在地面 -->
<arg name="R" default="0"/>
<arg name="P" default="0"/>
<arg name="Y" default="0"/>
```

```bash
source ~/setup_all_env.sh
roslaunch px4 mavros_posix_sitl.launch world:=$(rospack find my_gazebo_worlds)/worlds/my_world.world
```

正常情况：Gazebo 自动加载自定义世界，无人机出现在指定位置，传感器正常工作（新开终端 `rostopic list` 检查）。
