Grass and sand downloaded on 2026-10-22 from official Poly Haven API/CDN. Rock and mud maps were copied unmodified from the previous alpine_snow_1km source library and their SHA-256 hashes rechecked. No tree model was changed.

`sources.json` records original download URLs, exact local paths, SHA-256 digests, source MD5 where available, file sizes and image resolutions. API responses for new grass and sand are retained alongside them.

Textures describe appearance only. Contact/friction/softness must be set explicitly in Gazebo collision surfaces or plugins. Material map tiling scale may be chosen independently for the final terrain.
