# Original transmission corridor

Generated from original parametric geometry by `tools/generate_power_corridor.py` (MIT). No third-party tower mesh is included. Two 32 m lattice towers per instance, 160 m spacing, six phase wires and two shield wires. Static parabolic sag approximates the appearance of suspended cables; it is not a structural or electrical simulation. Collision geometry matches the visible steel, conductors and insulators.
